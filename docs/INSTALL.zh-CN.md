# 信息库 — 简体中文

1. 把 ZIP 解压到准备长期保留的文件夹。
2. 在 Chrome 116 或更新版本中打开 `chrome://extensions`。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」。
4. 选择解压后包含 `manifest.json` 的文件夹。
5. 在 Chrome 扩展程序菜单中固定「信息库」。
6. 点击工具栏图标，再点「新增」保存第一条信息。

每条信息由分类、名称和内容组成。「复制」仅复制内容并保留换行；铅笔编辑；垃圾桶直接打开删除确认。顶部可以搜索和筛选分类，底部可以导出、导入 JSON 备份。

点击「新增」旁的图钉可固定到 Chrome 侧栏，点击网页或切换标签时仍保持打开；点击浏览器侧栏顶部的 × 关闭。工具栏图标仍默认打开小弹窗。固定功能需在实际扩展中使用，网页示例不可固定。

关闭弹窗前需要点击「保存信息」。正常关闭弹窗或重启 Chrome 不会清空已保存的数据。卸载会删除本地信息，请定期导出备份；备份是包含个人内容的明文 JSON。

更新版本或切换语言时，先导出备份，把新文件覆盖到原安装文件夹，然后在 `chrome://extensions` 点击「重新加载」。从不同文件夹加载可能成为独立扩展，需要用 JSON 导出 / 导入转移数据。中英文备份互相兼容，个人内容不会翻译。

这是本地加载的扩展，没有上架 Chrome 应用商店。无服务器、账号、统计服务或网页读取权限。新安装为空库，示例数据只在开发网页预览中出现。
