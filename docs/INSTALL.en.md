# Application Info Panel — English

1. Extract this ZIP into a permanent folder.
2. Open `chrome://extensions` in Chrome 116 or later.
3. Enable **Developer mode**, then click **Load unpacked**.
4. Select the extracted folder containing `manifest.json`.
5. Pin **Application Info Panel** from Chrome's extensions menu.
6. Click the toolbar icon and use **Add** to save your first entry.

Each entry has a category, name and content. Copy copies only the content, including line breaks. The pencil edits; the trash icon opens a delete confirmation. Search and category filtering are at the top; JSON export/import are at the bottom.

Click the pin beside Add to keep the library open in Chrome's side panel while you browse or switch tabs. Close the panel with Chrome's × button. The toolbar icon continues to open the small popup. Pinning needs the installed extension; it is unavailable in the web demo.

Click **Save** before closing the popup. Saved data stays in this browser when you close the popup or restart Chrome. Uninstalling deletes local data. Export backups regularly; JSON files contain your information in plain text.

To update or change language, export a backup, replace the files inside the original installation folder, and click **Reload** in `chrome://extensions`. Loading a different folder may create a separate extension; transfer data using JSON export/import. Chinese and English backups are compatible. User content is not translated.

This is a local unpacked extension, not a Chrome Web Store listing. No server, account, analytics or webpage-reading permissions. Demo data appears only in the developer web preview, not in a new installation.
