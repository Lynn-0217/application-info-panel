# 信息库 · Application Info Panel

简体中文 · [English](README.md)

填不同的申请表时，你是不是总要翻出同一份资料，找学校地址、教育经历、论文引用，再复制过去？

信息库是一个放在 Chrome 右上角的小工具。把常用信息保存一次，下次填表时打开它，找到需要的那一条，点「复制」就能粘贴到网页里。不需要注册账号，信息保存在自己的浏览器中。

## 什么时候会用到？

- **申请学校或奖学金**：反复填写教育经历、研究经历、获奖信息、论文引用或推荐人联系方式。
- **求职或报名活动**：在不同网站填写同一段个人介绍、工作经历或通讯地址。
- **日常查阅**：把经常要用、又不想每次重新寻找的信息放在手边。

分类由你自己命名，可以按「基本信息」「教育」「论文」整理，也可以用适合自己的方式。每个分类都能保存多条信息。

## 第一次使用：安装到 Chrome

先到 [下载页面](https://github.com/Lynn-0217/application-info-panel/releases/latest)，在 **Assets** 中选择安装包：文件名以 `-zh-CN.zip` 结尾的是中文版，以 `-en.zip` 结尾的是英文版。

目前需要手动加载，暂未上架 Chrome 应用商店。使用 Chrome 116 或更新版本，按下面的步骤安装即可，无需安装其他软件。

1. 把下载的 ZIP 解压到一个准备长期保留的文件夹。
2. 在 Chrome 地址栏输入 `chrome://extensions` 并打开。
3. 开启右上角的「开发者模式」，点击「加载已解压的扩展程序」。
4. 选择解压后**包含 `manifest.json` 的文件夹**。如果外面还有一层文件夹，需要再打开一层。
5. 点击浏览器右上角的拼图图标，在「信息库」旁点击图钉，让它显示在工具栏上。

安装完成后，点击信息库图标就能打开面板。请保留解压后的文件夹，Chrome 后续仍需要读取里面的文件。

## 保存一条信息，再用到表格里

点击「新增」，填写三个地方。例如保存一段论文引用：

| 填什么 | 示例 |
| --- | --- |
| 分类：方便以后查找 | 论文 |
| 名称：让自己一眼认出这条信息 | 第一篇论文引用 |
| 内容：实际要粘贴到表格里的文字 | Chen, A. (2025). Learning from limited data. Example Journal of Research. |

点击「保存信息」，等到出现保存成功的提示。这条内容就留在信息库里了；内容可以写多行。

下次填写网页表格时：

1. 点击浏览器右上角的信息库图标。
2. 在顶部输入关键词，或选择分类，找到要用的信息。
3. 点这条信息旁的「复制」，回到表格输入框粘贴。

「复制」只复制你填写的内容，保留换行，不会带上名称和分类。粘贴后可以按当前表格的要求调整文字。

## 填表时，让信息库一直开着

默认的小弹窗会在你点击网页后收起。需要边看资料边填表时，点击**面板内「新增」旁的图钉**，就能转为 Chrome 侧栏；点击网页或切换同一窗口中的标签页时，侧栏会保持打开。用完后点击侧栏顶部的 × 关闭。

这里的图钉与浏览器拼图菜单里的图钉作用不同：拼图菜单中的图钉让扩展图标留在工具栏；面板里的图钉让信息库持续显示。

## 修改、删除和备份

信息有变化时，点击该条右上角的**铅笔**修改，再点「保存信息」。不需要的条目可以点**垃圾桶**删除，确认后才会删除。

底部的「导出」会下载一份包含全部信息的备份文件。换浏览器或换电脑后，安装扩展，再点「导入」选择这份文件即可。导入会保留已有信息，并跳过完全重复的条目。

## 信息会不会丢？其他人能看到吗？

**已保存的信息不会因为关闭面板或重启 Chrome 而消失。** 编辑时要先点击保存；没保存的修改在弹窗关闭后不会保留。

信息只保存在当前浏览器里，不会上传到这个 GitHub 仓库，也不会自动同步到其他电脑。扩展不需要账号，不读取你正在填写的网页。备份文件里包含你保存的全部内容，请自己妥善保管。

**卸载扩展会删除其中的信息，因此建议定期导出备份。** 更新版本或切换中英文时，先导出备份，把新包里的文件覆盖到**原安装文件夹**，然后在 `chrome://extensions` 点击扩展的重新加载按钮。从其他文件夹加载可能会成为另一份独立扩展，需要通过导入备份转移信息。中英文版的备份可以互用，保存的文字不会自动翻译。
